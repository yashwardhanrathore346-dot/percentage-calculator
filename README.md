 # Percentify – Smart Percentage Calculator

**Percentify** is a Java-based desktop application designed to make percentage-related calculations simple, fast, and efficient. Built using Java Swing and MySQL, the application provides an interactive dashboard, secure user login, multiple calculation tools, and a database-backed calculation history.

## ✨ Features

- **User Authentication:** Login system for accessing the application.
- **Basic Percentage Calculator:** Calculate percentages of given values.
- **Percentage Increase:** Calculate percentage growth between two values.
- **Percentage Decrease:** Calculate percentage reduction.
- **Combined Percentage:** Calculate successive percentage changes.
- **Discount Calculator:** Calculate discount amounts and final prices.
- **CGPA to Percentage:** Convert CGPA into percentage.
- **Marks Percentage:** Calculate marks obtained as a percentage.
- **Calculation History:** Save and view previous calculations.
- **MySQL Database:** Store user information and calculation history persistently.
- **Interactive Dashboard:** Access calculator tools and history through a user-friendly interface.

## 🛠️ Technologies Used

- Java 17
- Java Swing (GUI)
- MySQL
- JDBC (Java Database Connectivity)
- IntelliJ IDEA

## 🎯 Project Objective

The main objective of Percentify is to develop a simple and interactive desktop application that automates common percentage calculations while providing reliable data storage and easy access to previous calculations.
